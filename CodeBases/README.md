# Contact Management System

A simple command-line contact management program written in Python. This project was created for a college assignment.

## Features

- Add a contact with a name, phone number, and optional email
- Display all saved contacts
- Search for a contact by name
- Update a contact's phone number
- Delete a contact
- Check that phone numbers contain 10 digits and are not already in use

## Requirements

- Python 3

No additional packages are required.

## Run the Program

Open a terminal in the project folder and run:

```bash
python main.py
```

Follow the menu options shown in the terminal.

## Note

Contacts are stored temporarily while the program is running. They are cleared when the program exits.
